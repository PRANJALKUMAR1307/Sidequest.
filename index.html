LOCAL AI SETUP

Sidequest uses the open-source Qwen model through Ollama. Your friend's details stay on your computer.

How to set up
  1. Install Ollama.
  2. Run ollama pull qwen2.5:3b in your terminal.
  3. Start Ollama, then run python server.py in the project folder.
  4. Open http://127.0.0.1:8000 in your browser.
